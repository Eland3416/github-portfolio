# Evan Landry — GitHub Portfolio

A responsive personal portfolio website for Evan Landry, a Computer Science student pursuing software development opportunities.

## Live website

After enabling GitHub Pages, the site will be available at:

https://eland3416.github.io/github-portfolio/

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or package installation are required.
